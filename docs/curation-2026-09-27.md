## 재현 기록

생성은 모두 OpenAI 내장 `image_gen`으로 수행했다. 내장 도구의 세부 모델 버전을 임의로 추정하지 않았다. `target_model`은 원문의 표기이고, 원문에 명시되지 않은 경우 `모델 미명시`로 기록했다. `result_engine`은 실제 사용한 도구다.

각 항목의 원문은 `prompt`, 한국어 설명과 선정 이유는 `prompt_ko`, 실제 생성 지시는 `gen_prompt`에 저장했다. 편집이 필요한 경우 `gen_edit_prompt`도 보존했다. `ref_image`는 원본 X 게시 이미지이고 `result`는 직접 생성한 결과다. `review_batch`는 `20260927-curated-hour`다.

- 음식 워드마크: 첫 결과에서 BURGER의 U가 아이콘으로 대체되었다. U의 열린 속공간을 복원하는 편집 후 채택했다.
- 바이올린 그림자: 첫 결과의 그림자에서 몸통과 목의 순서가 뒤집혔다. 몸통이 가까이, 목과 스크롤이 멀리 놓이도록 수정했다. 정밀한 광학 도해가 아닌 초현실 편집 이미지로 설명했다.
- 항구 사진→선화: 4:3 입력 사진부터 직접 생성한 뒤 2:3 포스터로 확장했다. 사진 속 밧줄이 경계의 같은 위치에서 펜선과 인물의 손까지 연결되는지 확인했다. 입력 사진과 생성 프롬프트도 보존했다. 상단 사진은 장면과 구도를 유지하지만 픽셀 단위 동일 복사본은 아니다.
- 동굴 벽화: 자전거를 소재로 한 가상 작품으로 표기했다. 실제 유적 기록으로 제시하지 않는다.
- 색면 회화: 이미지 ALT의 등대·빨강·슬레이트 블루 예시를 확인했다. 색의 상하 배치가 아니라 큰 색면과 작은 대상의 위계를 재현했다.
